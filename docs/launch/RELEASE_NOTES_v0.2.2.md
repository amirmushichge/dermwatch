# DermWatch v0.2.2

DermWatch v0.2.2 makes the product's medical limits explicit wherever users
first encounter it.

## What changed

- added a persistent medical-safety notice to the main application screen;
- states plainly that DermWatch does not detect or rule out skin cancer or
  melanoma;
- clarifies that the app cannot confirm that a spot is benign and does not
  provide a diagnosis or cancer-risk score;
- updated the README, disclaimer, technical transparency document, and launch
  visual with the same language;
- added regression tests so this safety wording cannot disappear unnoticed.

## Medical limitation

DermWatch is an experimental visual photo journal, not a medical device or a
skin-cancer diagnosis system. Its image-processing heuristics have not been
clinically validated. A new, changing, different, itching, bleeding, or
otherwise concerning spot should be assessed by a qualified clinician.
