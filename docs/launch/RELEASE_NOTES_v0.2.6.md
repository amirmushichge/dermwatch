# DermWatch v0.2.6

DermWatch v0.2.6 adds a visible delete control to every record card.

## What changed

- each record has a dedicated × button in its top-right corner;
- deleting still requires explicit confirmation;
- clicking elsewhere on the card continues to open the record;
- the delete control uses a separate accessible button with a readable label
  and a 28 × 28 px target.

Deleting a record removes that record and all photos stored inside it. Export a
private backup first if those photos may be needed later.
