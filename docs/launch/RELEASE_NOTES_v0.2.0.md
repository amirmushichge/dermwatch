# DermWatch v0.2.0

DermWatch is now available for Windows, macOS, and Android.

## Downloads

- `DermWatch-0.2.0-win-x64.exe` — Windows x64 installer
- `DermWatch-0.2.0-mac-universal.dmg` — Apple Silicon and Intel macOS
- `app-release.apk` — signed Android APK

No Node.js, terminal, account, cloud service, or separate database is required.

## What changed

- added a universal macOS build;
- added an Android app with direct camera/file selection;
- added private native Android storage with system backup disabled;
- added stable APK signing so future versions can update in place;
- added three-platform release automation and signature verification;
- added explicit credits, third-party notices, and technical transparency.

## Important limitation

DermWatch is an experimental visual photo journal, not a medical device or a
skin-cancer diagnosis system. Its hand-written image-processing heuristics have
not been clinically validated. Do not delay professional care because of a
DermWatch result.
