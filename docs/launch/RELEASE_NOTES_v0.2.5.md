# DermWatch v0.2.5

DermWatch v0.2.5 makes photo records easier to read and more useful from the
first image.

## What changed

- increased the size of meaningful labels, measurements, explanations, and
  statuses throughout the record screen;
- constrained the desktop workspace to keep related information together on
  wide monitors;
- reduced excess spacing in the record list, result summary, ABCDE cards, and
  photo comparison area;
- added a single-photo summary with photo quality, measured-feature count, and
  the number of higher photo-only measurements;
- added visible 0–100 photo-measure values for asymmetry, border, and color;
- improved the compact mobile header and prevented the statistics card from
  overflowing narrow screens.

The values remain experimental photo measurements. They are not a diagnosis,
cancer-risk score, or benign/malignant classification.
